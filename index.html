About YatraAI — Smart Tourism Information System

YatraAI is a user-friendly Smart Tourism web application designed to help tourists plan hassle-free trips. Tourists simply select their destination, budget, trip duration, and personal interests, and the system generates a complete day-by-day itinerary with optimal travel routes and transparent cost estimates.

1. Personalized Recommendations

Matches tourist attractions to user interests (Heritage, Nature, Adventure, Food, Shopping) and stay preferences.

2. Smart Budget Planner

Calculates realistic expenses across hotels, local transport, food, and entry tickets so travelers stay within budget.

3. Optimal Route Sequencing

Finds the shortest path between attractions each day so tourists spend less time in traffic and more time exploring.
